# Abdullah Alsehli — Portfolio

Static personal portfolio. Plain HTML/CSS/JS, no build step.

```
index.html        page content
css/style.css     styles (dark/light theme tokens at the top)
js/main.js        theme toggle, mobile menu, scroll reveal, hero canvas
assets/           favicon
```

## Run locally

```bash
python -m http.server 5470
```

Then open http://localhost:5470.

Any static host works (GitHub Pages, Netlify, Vercel). For GitHub Pages, push this folder to a repo and enable Pages from the `main` branch root.
